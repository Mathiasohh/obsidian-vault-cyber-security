Write fungere således:
Løs udtrykket og skriv resultatet

Eks.

```ocaml
Given 3 4 then  10 21

write 7 + 3
write 7 * read
```
eller

```ocaml
Given 3 4 then  10 28

write 7 + read
write 7 * read
```

Skrives ud på denne måde

```ocaml
Write read * (read + read)
(* Dette skrives på følgende måde: *)

read
read
read
add
mul
wrt
```
