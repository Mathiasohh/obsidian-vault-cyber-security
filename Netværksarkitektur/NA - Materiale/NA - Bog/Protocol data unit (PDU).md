Står for ***Protocol Data Unit***, også kendt som ***Data Service Unite***

PDU'er kan fremkomme med forskellige addons alt efter laget i [[OSI Model]].

De er følgende:

| Layer              | Added name |
| ------------------ | ---------- |
| 4. Transport Layer | Segments   |
| 3. Network layer   | Packets    |
| 2. Data Link Layer | Frames     |
| 1. Physical Layer  | Bits       |
